# ZJ Ersatzteile – Premium GitHub Pages Website

## Veröffentlichung über iPhone
1. ZIP-Datei in der Dateien-App öffnen, um sie zu entpacken.
2. In Safari https://github.com/ZjErsatzteile/ZJ.ErsatzTeile öffnen und anmelden.
3. Falls nötig: `aA` in der Adressleiste → `Desktop-Website anfordern`.
4. `Add file` → `Upload files` wählen.
5. Die enthaltene `index.html` auswählen und hochladen.
6. `Commit changes` antippen.
7. Unter `Settings` → `Pages` `Deploy from a branch` wählen, Branch `main`, Ordner `/ (root)`, dann `Save`.

Die Seite ist statisches HTML; es ist kein Build-Schritt nötig. Produktfotos werden über Unsplash geladen und benötigen Internet.
